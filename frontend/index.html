02 Training Dynamics
Loss vs training step (COLAB-SCALE, Tatoeba EN-DE)
Learning rate schedule (d_model=256, warmup=2000)
Configuration
COLAB-SCALE: 3 layers, d_model=256, 4 heads, d_ff=1024. The Transformer Base architecture (6L d512) is fully implemented but requires more compute than a single Colab session allows.
Optimizer
Adam with paper values: beta_1=0.9, beta_2=0.98, epsilon=1e-9. Learning rate follows the original warmup and inverse square root decay schedule from Section 5.3.
Label smoothing
epsilon=0.1 as per Section 5.4. Implemented manually with explicit PAD masking. The theoretical minimum loss with smoothing is not zero, so accuracy was used as the convergence metric during the toy overfit test.
Session recovery
Checkpoints saved every 1000 steps in both TF format and .weights.h5. TF checkpoint restore was found unreliable across sessions due to a Keras build ordering issue. h5 weights are the primary recovery mechanism.
Result
Train loss 5.38 to 2.14 over 10,000 steps in 35 minutes. Validation loss 4.36 to 2.63, tracking train loss with no divergence.

04 Implementation Architecture
attention.py
Scaled Dot-Product Attention
Manual implementation of Attention(Q,K,V) = softmax(QK^T / sqrt(d_k))V. Includes padding mask, look-ahead mask, and gradient flow verification.
Phase 4
multi_head_attention.py
Multi-Head Attention
Four projection matrices W_Q, W_K, W_V, W_O. Split-heads and merge-heads implemented manually. No tf.keras.layers.MultiHeadAttention used.
Phase 5
positional_encoding.py
Sinusoidal PE
Exact formula from Section 3.5. Pre-computed at init. Relative position property verified numerically. Embedding scaling by sqrt(d_model) included.
Phase 6
encoder.py / decoder.py
Encoder and Decoder Stacks
POST-LN architecture following the original paper. Residual connections and LayerNorm verified. Decoder causal mask tested across all heads.
Phase 8 / 9
training.py
Training Infrastructure
Label smoothing loss, original LR schedule, gradient clipping, checkpoint management, session recovery, and experiment logging to CSV.
Phase 11
decoding.py / bleu.py
Decoding and Evaluation
Greedy decoding with repeat penalty. Beam search with length penalty (paper: k=4, alpha=0.6). BLEU-4 implemented from scratch with modified precision and brevity penalty.

06 Dataset Strategy
stage dataset size purpose status
A Handmade EN-DE 20 pairs Pipeline smoke test. Toy overfit verification. Completed
B Tatoeba EN-DE (OPUS) ~80k pairs BPE vocab training. Full training run. BLEU evaluation. Completed
C WMT14 subset up to 500k pairs Intermediate scaling experiment. Reserved. Reserved
D WMT14 EN-DE full ~4.5M pairs Paper reproduction target. Requires multi-GPU. Reserved

Stages C and D were reserved. The project reached Stage B and validated the full pipeline end-to-end. Full WMT14 training requires sustained multi-GPU access beyond single Colab limits.
